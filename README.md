# 12366 纳税服务热线坐席服务辅助系统

本项目是一个面向 12366 来电场景的演示系统。坐席输入来电号码后，系统从本地画像库调取历史信息，快速展示近期服务情况，并实时生成个性化接待建议。

系统不会根据画像直接回答具体税费政策问题。画像用于帮助坐席选择沟通方式、衔接历史事项和识别需要优先关注的服务节点。

## 主要功能

- 坐席接待助手：展示最近五个工作日的信息速览、历史重点问题和实时接待建议；
- 画像数据概览：展示来电趋势、咨询主体、个人与企业问题解决情况、五项历史服务事实、登记单位服务效果，以及可下钻的专题类别统计；
- 历史来电记录：分页查看来电轨迹，并查看单通原始登记信息和关键结构化结果；
- 画像推演中心：以动态三维关系图展示画像字段、三类组合接待方式和判定规则，并支持模拟增量变化；
- 用户与权限：管理员可访问全部功能并管理账号，坐席不能访问画像推演和用户管理。

## 画像与接待模式

画像聚焦纳税人近期状态和明确历史事实，不设置“综合画像”。

| 维度 | 分类或事实 | 说明 |
| --- | --- | --- |
| 业务专业度 | 专业、了解、小白 | 根据业务表达、术语理解和办理节点认知判断 |
| 近期情绪状态 | 平稳、焦虑、不满 | 只描述文本中可观察到的近期表达 |
| 历史服务事实 | 等待推诿、历史工单、异常中断、联系后未解决、对坐席不满 | 按最近五个工作日的来电记录聚合 |

接待方式采用“类别内唯一、类别间组合”的确定性规则，不再由单一高优先级模式覆盖其他信息：

| 服务类别 | 可选方式 | 主要依据 |
| --- | --- | --- |
| 表达方式 | 结论直述、重点解释、通俗引导 | 业务专业度 |
| 情绪响应 | 安抚修复、稳定预期、平稳接待 | 近期情绪状态、等待推诿、对坐席不满 |
| 业务应对 | 历史诉求跟进、当前诉求确认 | 历史工单、异常中断、联系后未解决 |

系统从每个类别中选择一项，并按“表达方式、情绪响应、业务应对”组合呈现。例如，专业且表达不满、同时存在历史工单时，结果为 `结论直述 · 安抚修复 · 历史诉求跟进`。大模型必须同时依赖三个分项方式和脱敏后的历史信息生成宏观建议，结果实时返回，不写入画像数据库。

## 数据处理方式

- 首次构建：1—9 日记录优先复用已有分析字段，可选择本地规则预览，也可调用模型补齐业务专业度、近期情绪状态等画像字段；10 日及以后记录按原始数据调用模型重新分析。
- 一级专题和二级专题直接读取输入表的“一级专题类别”和“二级标签”列。
- 增量更新：每次加入一个 Excel 文件，文件可包含一天或多天数据，只处理新增记录并更新对应号码画像。
- 来电轨迹完整保留输入表 A—P 列，同时保存必要的结构化分析字段。
- 来电号码按原始记录保存，不限制固定位数；查询和模型请求前分别执行本地安全匹配与文本脱敏。

## 快速启动

### 1. 安装依赖

```bash
python -m pip install -e .
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，填写模型配置、号码保护密钥和演示账号。可使用以下命令生成本地密钥：

```bash
python scripts/generate_local_secrets.py
```

默认演示账号为：

- 管理员：`admin` / `Admin@12366`
- 坐席：`agent` / `Agent@12366`

如用于非本机演示，请先在 `.env` 中修改默认密码。

### 3. 使用 smoke 演示库启动

仓库已生成 9 条记录的演示数据库：

```bash
python scripts/run_demo.py --database data/database/smoke_test_realtime.sqlite3
```

浏览器访问：<http://127.0.0.1:8000>

停止服务请按 `Ctrl+C`。

### 4. 本地规则预览

仅构建 1—9 日历史基底，不调用模型：

```bash
python scripts/init_database.py data/raw/raw_data.xlsx \
  --database data/database/raw_data_rules_preview.sqlite3 \
  --history-only --rebuild
```

启动预览库：

```bash
python scripts/run_demo.py --database data/database/raw_data_rules_preview.sqlite3
```

### 5. 从正式数据重新构建

```bash
python scripts/init_database.py data/raw/raw_data.xlsx \
  --analyze-history-with-model --rebuild
```

构建完成后直接启动：

```bash
python scripts/run_demo.py
```

## 增量更新

指定一个新 Excel：

```bash
python scripts/update_database.py data/raw/新增来电.xlsx
```

## 规则表与结果导出

画像方法论已输出为：

- `data/output/纳税人特征与接待模式映射表.xlsx`：说明画像维度、字段口径、模式映射规则及典型推导结果。
- `data/output/接待模式服务建议表.xlsx`：说明三类八项分项方式、18种组合策略及典型应用场景。

导出当前画像、来电轨迹和更新摘要：

```bash
python scripts/export_results.py
```
