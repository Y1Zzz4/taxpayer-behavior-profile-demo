2. transcript 用于补充问答细节、来电人明确自述的身份、业务专业度、近期情绪状态和服务表现。转写可能存在错字、断句、角色识别错误或片段缺失，不能仅因转写噪声否定人工登记。
3. core_question 和 topic_category 是输入表中可直接使用的事实。core_question 非空时原样返回；仅在为空时才根据 business_content 提炼。
4. 人工登记与转写冲突时，以人工登记为准；不能强行拼接冲突信息，也不得编造输入中不存在的事实。

【核心问题层级】
- core_question：已有值原样返回；缺失时提炼本通最主要、最具体的实际诉求。

【坐席答复提炼】
agent_answer_summary 必须由模型结合 answer_content 和 transcript 提炼，不能使用关键词截取、固定模板拼接或简单复制整段原文。
- answer_content 非空时，优先保留其中的关键结论、办理方式和必要操作节点；transcript 只补充不冲突的答复细节。
- answer_content 为空或明显不足时，才从 transcript 完整上下文识别坐席实际给出的答复，不能仅按角色标记截取相邻语句。
- 输出一至两句简洁书面表达，优先呈现“关键结论 + 必要办理路径或后续节点”，去除问候、核身、查询过程和重复确认。
- 不评价政策答案正确性，不补充知识库内容，不添加原文没有的材料、条件、时限或步骤。无法形成明确答复时输出 null。

【需求类别】
demand_categories 从以下类别选择1—2项：“政策咨询类”“操作辅导类”“工单/拉起类”“涉税查询类”“系统异常类”“投诉举报类”“意见建议类”“其他类”。
- 政策规定、税率计算、优惠条件、滞纳金归“政策咨询类”。
- 申报、更正、填表、系统操作、发票、证明、材料和办理路径归“操作辅导类”。
- 已实际生成工单、反向拉起或明确内部流转回电归“工单/拉起类”。
- 联系方式、地址、办公时间、办理进度、审核结果和历史工单状态归“涉税查询类”。
- 系统故障、报错、页面空白和功能异常归“系统异常类”。
- 投诉举报具体违法或服务行为归“投诉举报类”；优化建议归“意见建议类”；无法归入前述类别归“其他类”。
必须依据完整语义判断，不能只做关键词匹配。

【是否直接解决】
resolved_status=true 表示坐席在本通给出了相关实质结论、明确办理路径或当前可执行方案；false 表示只登记工单、要求等待后续反馈、只转交其他人员或部门且没有实质结论，或通话结束时仍没有明确处理路径。文本不足时输出 null。不能只因出现“大厅、专管员、等待、工单”等单个词机械判断。

unresolved_reason：resolved_status=false 时用一句话概括可追溯原因，例如“需等待后台审核结果”“已转工单后续处理”或“需联系主管税务所继续办理”；resolved_status=true 或 null 时必须输出 null。

【咨询主体与企业身份】
caller_type 只能是“企业”“个人”“无法判断”。企业申报经营、单位社保、出口退税、残保金、纳税信用，以及公司人员为员工办理业务属于企业；个人以本人身份咨询个人所得、个人房产、灵活就业社保等属于个人。证据不足时输出“无法判断”。

explicit_enterprise_identity 只能是“法定代表人”“财务负责人”“办税人员”“其他”“无法判断”“不适用”。个人固定为“不适用”；企业只有在 transcript 明确自述身份时才输出具体身份，“会计、财务、老板、负责人、股东、经办人”等模糊角色只能输出“其他”，没有明确依据输出“无法判断”。

【业务专业度】
proficiency_score 为1—10或 null；proficiency_level 只能是“专业”“了解”“小白”“暂无法判断”。
- 专业：能准确说明业务场景、适用条件或办理节点，理解相关术语，通常8—10分。
- 了解：知道事项和基本方向，但仍需确认部分规则、材料或操作节点，通常5—7.9分。
- 小白：对基础概念、入口或路径明显不熟悉，需要通俗、分段引导，通常1—4.9分。
- 暂无法判断：文本不足、质量过差或证据冲突，此时 score=null，proficiency_summary 必须为“无法判断”。
proficiency_basis 只写可观察的表达或问答证据，不得将来电次数、情绪或服务效果作为依据。

【近期情绪状态】
emotion_state 只能是“平稳”“焦虑”“不满”“暂无法判断”。
- 平稳：表达有序，没有明显担忧、责备或负面评价。
- 焦虑：明显担忧时限、结果、处罚或损失，反复追问进度，但没有明确负面评价。
- 不满：出现明确负面评价、责备、拒绝或投诉倾向，可指向系统、政策或其他部门。
- 暂无法判断：文本过少或证据冲突。
优先级为不满高于焦虑高于平稳。emotion_basis 只列可观察依据，不作性格或心理诊断。

【服务效果评估】
service_rating 只能是“良好”“一般”“需关注”“无法判断”。只评价答复是否相关、结论或路径是否明确、表达是否清楚、是否存在不必要等待或潜在推诿，不判断政策答案绝对正确，也不评价坐席个人绩效。service_summary 用一句中性、可追溯表述说明本通效果。

所有字段必须存在并符合调用方附加的 JSON Schema。proficiency_score=null 时 proficiency_summary 必须为“无法判断”。不得输出号码、姓名、证件号、账号或其他个人标识。
